## 2. 数据计算逻辑

### 2.1 每日最热股票（Daily Nasdaq Tech Hot Stocks）

- 先看成交活跃度，再看当日涨跌表现
- 具体逻辑是先按成交量做一次优先筛选，再按涨跌幅排序，最后取前 3 只

### 2.2 个股技术面计算

- 指标输入统一基于日线 OHLCV（开高低收量）序列，按交易日升序计算
- 均线与趋势：
  - MA5 / MA10 / MA20：对应 5、10、20 日收盘均价
  - 趋势主判定：MA5 > MA10 > MA20 记为多头结构；MA5 < MA10 < MA20 记为空头结构
  - 强弱判定：比较当前与前 5 日的 MA5-MA20 间距，若间距扩大且超过 5%，记为强势趋势
- 乖离率（BIAS）：
  - 计算口径：BIAS(MA5) = (现价 - MA5) / MA5 × 100%，MA10/MA20 同理
  - 严进约束：默认 BIAS 阈值 5%；超过阈值提示“不追高”
  - 强势补偿：当处于强势多头且趋势强度高时，阈值放宽到 1.5 倍
- MACD：
  - EMA12、EMA26、DIF=EMA12-EMA26、DEA=DIF 的 9 日 EMA、MACD 柱=(DIF-DEA)×2
  - 重点事件：零轴上金叉、普通金叉、死叉、上/下穿零轴
- RSI：
  - 使用 RSI6 / RSI12 / RSI24
  - RSI12 作为主读数：>70 视为超买，<30 视为超卖
- 量能与支撑压力：
  - 量比 = 当日成交量 / 近 5 日均量
  - 支撑识别：价格在 MA5 附近（1% 容差）或 MA10 附近（2% 容差）且未跌破
  - 压力识别：近 20 日高点作为主要压力位
- 综合评分（100 分）：
  - 趋势 30 分、乖离率 20 分、量能 15 分、支撑 10 分、MACD 15 分、RSI 10 分
  - 输出信号分级：强买入 / 买入 / 持有 / 等待 / 卖出 / 强卖出

### 2.3 交易信号与建议生成

- 信号生成应遵循以下核心约束：
  - 趋势优先：以 MA5 > MA10 > MA20 识别多头趋势结构
  - 禁止追高：当价格乖离率超过阈值（默认 5%，可配置）时触发风险提示；强趋势场景可放宽阈值
  - 点位输出：给出买入价、止损价、目标价三类关键点位，计算逻辑如下
    - 买入价（Entry）：
      - 多头回踩场景：理想买入点 = MA5，次优买入点 = MA10（缩量回踩策略）
      - 放量突破场景：理想买入点 = 突破位附近（阻力位上方确认区）
      - 箱体震荡场景：买入点 = 箱体支撑附近（距支撑不超过 5%）
    - 止损价（Stop Loss）：
      - 多头回踩：止损位 = MA20
      - 放量突破：止损位 = 突破位下方 3%
      - 箱体震荡：止损位 = 箱体底部下方 3%
      - 波浪/结构策略：止损位取关键结构失效点（如前低/关键浪起点）
    - 目标价（Take Profit）：
      - 趋势延续：首目标 = 近 20 日高点或已识别阻力位
      - 箱体突破：新目标 = 突破位 + 箱体高度
      - 波浪结构：按浪形延伸比（如第 3 浪常见 1.618~2.618）给出目标区间
      - 无显著空间时，明确“暂不出手”，避免为给目标而给目标

### 2.4 Dashboard 已展示指标的计算与解释

- Market Sentiment：
  - 当前实现直接读取技术指标中的 RSI 数值，并用 0-100 仪表盘展示
  - 解释口径：数值越高代表情绪越偏强，越低代表情绪越偏弱
- Volatility (30D)：
  - 基于日收益率序列计算标准差，再乘以 √252 年化，最后转为百分比
  - 解释口径：波动率越高，短期价格不确定性越强
- Volume：
  - 当前展示为最新成交量原始值（格式化后显示）
  - 解释口径：用于判断当前交易活跃程度
- SMA (20)：
  - 当前实现为详情面板内可见日线样本收盘价的算术平均
  - 解释口径：用于观察当前价格相对中短期均值位置
- EMA (12)：
  - 使用 12 日指数加权移动平均，近期价格权重更高
  - 解释口径：比 SMA 对短期拐点更敏感
- ATR (14)：
  - 以真实波幅 TR 的均值衡量波动区间，TR 取 high-low、|high-prevClose|、|low-prevClose| 三者最大值
  - 解释口径：ATR 越高，单日价格振幅通常越大

## 3. UX 逻辑

### 3.1 热股 -> 自选

- 用户在“每日最热股票”中可直接点击 Add 加入自选
- 已在自选中的股票显示 Added 并禁用重复添加
- 结论：每日最热股票可以直接被添加到自选股

### 3.2 自选 -> 详情

- 点击左侧自选项，右侧详情立即切换到对应股票
- 用户在同一屏完成“看榜单、切股票、看指标、看建议”的连续操作

### 3.3 数据卡片 -> 问答

- 指数、新闻、情绪、K 线、交易指标卡片均可一键触发提问
- 交互目标是让用户从“看数据”快速进入“问解释”，降低分析操作门槛
